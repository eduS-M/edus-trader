1Introduccion

Que es el Post-Market Automatizado?

Un sistema que analiza automaticamente los trades ejecutados durante la sesion de trading, los evalua contra las reglas del HUD V5, compara con el game plan del dia, y genera un informe post-market completo con matriz DOFA, analisis de stops y recomendaciones.

Que hace?

Lee los archivos CSV exportados por NinjaTrader 8 desde la carpeta Post-Mercado/{YYYYMMDD}/, construye un prompt compacto con todos los trades y contexto de indicadores, lo envia a una IA (Groq, Gemini, Ollama, etc.), recibe un analisis JSON estructurado, genera un HTML profesional con estilo EduS Trader, y lo publica automaticamente en edustrader.pages.dev via git push. Tambien actualiza los menus laterales y la pagina de inicio con un resumen de la sesion.

2Arquitectura

Como funciona el sistema

El flujo completo es una cadena de 4 pasos: desde los CSVs de NinjaTrader hasta la publicacion en la web.

1. CSV NT8 → 2. Prompt compacto + Gameplan → 3. IA (Groq/Gemini/Ollama/etc) → 4. HTML + git push → edustrader.pages.dev
Tiempo total estimado: 10-25 segundos (dependiendo del proveedor IA y cantidad de trades)

Template HTML - Secciones del Post-Market

El HTML generado contiene las siguientes secciones:

  1. RESUMEN: Tarjetas con total trades, wins, losses, win rate, PnL total, avg trade, mayor win, mayor loss.
  2. ESTRATEGIAS: Tabla desglosada por estrategia con trades, wins, losses, WR y PnL.
  3. CONTEXTO: Tablas de indicadores por entry (VWAP, SMA20, SMA80, Keltner, ATR, POC).
  4. VOLATILIDAD: Analisis de VIX, Keltner, ATR y si las definiciones del dia fueron correctas.
  5. GAMEPLAN: Evaluacion de cumplimiento del game plan del dia.
  6. STOPS: Analisis detallado de stops ejecutados con recomendaciones.
  7. DOFA: Matriz de fortalezas, debilidades, oportunidades y amenazas de la sesion.
  8. RECOMENDACIONES: Recomendaciones especificas y bugs/incidencias tecnicas.
  9. ANALISIS IA: Resumen ejecutivo y nota final generados por la IA.
  10. TABLA COMPLETA: Todos los trades con precios, horarios, estrategia y PnL.
3Instalacion

Requisitos y puesta en marcha

El sistema funciona en Windows con Python 3.11+. No requiere servidor ni cuenta paga.

Requisitos del sistema

  • Windows 10/11
  • Python 3.11 o superior
  • Conexion a internet (para API de IA y git push)
  • Git instalado (para publicar en GitHub / Cloudflare Pages)
  • NinjaTrader 8 configurado para exportar CSVs a Post-Mercado/{YYYYMMDD}/

Paso a paso

Paso 1
Verificar Python

Abre PowerShell y ejecuta:

python --version

Debe mostrar Python 3.11.x o superior. Si no lo tienes, descargalo de python.org.

Paso 2
Instalar dependencias
cd "eduSTrader - Local Free\gameplan_system"
pip install openai anthropic requests

Dependencias necesarias segun el proveedor IA que uses:

  • Groq: Solo openai (usa API compatible)
  • Gemini: requests
  • Ollama: Solo openai (API compatible)
  • OpenAI: openai
  • Anthropic: anthropic
Paso 3
Configurar API keys en config.json

Edita gameplan_system/config.json y coloca las API keys:

{
  "ai": {
    "default_provider": "groq",
    "temperature": 0.7,
    "max_tokens": 8192,
    "providers": {
      "groq": {
        "enabled": true,
        "api_key": "gsk_tu_key_aqui",
        "model": "llama-3.3-70b-versatile",
        "base_url": "https://api.groq.com/openai/v1"
      }
    }
  }
}

Donde conseguir las keys:

  • Groq: console.groq.com → registrarse → API Keys → Crear key
  • Gemini: aistudio.google.com → Get API key
Paso 4
Configurar carpeta Post-Mercado en NT8

En NinjaTrader 8, asegurate de que las exportaciones CSV se guarden en:

C:\Users\eduar\OneDrive - Desarrollo Personal\Documents - Operativa Diaria\
EduSTrader - Local Free\Post-Mercado\{YYYYMMDD}\

Los archivos esperados son:

  • trades-NinjaTrader Grid *.csv — Trades por trade
  • EduS_TradesContext*.csv — Contexto de indicadores por entry
  • Orders-NinjaTrader Grid *.csv — Ordenes (opcional)
Paso 5
Ejecutar por primera vez (modo manual)

Para probar sin API key:

python generar_postmarket.py

Selecciona la opcion 6) MANUAL. Esto genera el archivo prompt_postmarket_data.txt. Copia su contenido, pegalo en ChatGPT/Claude web, guarda la respuesta como JSON y luego:

python generar_postmarket.py --manual-text respuesta_postmarket.json --auto

Cada modo tiene su propio flujo. El sistema te pregunta al inicio cual usar.

Modo Manual (Sin API key)

Como funciona

Ideal si no tienes API key o quieres usar ChatGPT/Claude desde el navegador web (versiones gratuitas).

  1. Ejecutas python generar_postmarket.py y eliges opcion 6
  2. El sistema genera prompt_postmarket_data.txt con los datos de la sesion
  3. Abres el archivo, copias TODO su contenido
  4. Lo pegas en ChatGPT, Claude o Gemini (web, version gratuita)
  5. La IA te devuelve un JSON con el analisis completo
  6. Copias esa respuesta y la guardas en un archivo (ej: respuesta_postmarket.json)
  7. Ejecutas: python generar_postmarket.py --manual-text respuesta_postmarket.json --auto
  8. El sistema genera el HTML y lo publica
Ejemplo completo
# Terminal 1: Generar el prompt
python generar_postmarket.py
> Elegir opcion 6
> Se genera prompt_postmarket_data.txt

# Abrir prompt_postmarket_data.txt, copiar, pegar en chat.openai.com

# Guardar respuesta como respuesta_postmarket.json

# Terminal 2: Cargar respuesta y completar
python generar_postmarket.py --manual-text respuesta_postmarket.json --auto

# Con fecha especifica:
python generar_postmarket.py --date 20260522 --manual-text respuesta_postmarket.json --auto

Skip AI (Solo datos)

Para que sirve
  • Verificar que los CSVs se leen correctamente
  • Probar el template HTML sin llamar a la IA
  • Generar un HTML rapido con solo las tablas de datos
  • Depurar problemas de parseo de CSVs
python generar_postmarket.py --skip-ai
python generar_postmarket.py --date 20260522 --skip-ai

Paso 4
Se genera el prompt compacto

El prompt incluye en formato CSV compacto (ahorrando ~90% de tokens respecto a JSON):

  • Todos los trades en formato linea: #|Inst|Dir|Entry|Exit|Px|Qty|PnL|Estrategia

  • analisis_trades: Evaluacion individual de CADA trade contra reglas HUD V5
  • analisis_stops: Patrones y recomendaciones sobre stops
  • matriz_dofa: Fortalezas, debilidades, oportunidades, amenazas
  • recomendaciones: Acciones concretas para mejorar
  • bugs_incidencias: Problemas tecnicos detectados

7Resultados

Que contiene el HTML generado

El Post-Market generado incluye analisis completo de la sesion. Esto es lo que debe contener cada seccion.

Header

Logo "EduS Trader", fecha completa (ej: "Sabado 23 de Mayo 2026"), tipo de analisis (Post-Market / Cierre Semanal / Cierre Mensual), y el PnL total de la sesion con codigo de color (verde = positivo, rojo = negativo).

RESUMEN

Grid de 8 tarjetas con metricas clave:

  • Total Trades, Wins, Losses
  • Win Rate (%)
  • Total PnL ($)
  • Avg Trade ($)
  • Mayor Win ($) y Mayor Loss ($)
  • Todo codificado por color (verde/rojo)

ESTRATEGIAS

Tabla desglosada por cada estrategia utilizada (HUD_Manual, HUD_Scalper, etc.) mostrando trades totales, wins, losses, flats, win rate y PnL. Ordenado por PnL descendente.

CONTEXTO

Tablas de indicadores por cada entry de trade, mostrando:

  • Direccion (Long/Short con iconos de color)
  • VWAP direction (UP/DOWN) y precio
  • Pendientes SMA20 y SMA80
  • LinReg89
  • Distancia a SMA20 y SMA80
  • Keltner Width y ATR
  • Window POC

VOLATILIDAD

  • VIX Observado: Valor y contexto del VIX en la sesion
  • Definiciones Correctas: Si las definiciones de volatilidad del pre-market fueron adecuadas
  • Relacion VIX/Keltner/ATR: Analisis de la volatilidad observada
  • Nota de Volatilidad: Detalle adicional sobre el comportamiento de la volatilidad

GAMEPLAN

  • Cumplimiento: SI / NO / PARCIAL (con codigo de color)
  • Desviaciones: Lista de puntos donde la operativa se desvio del plan
  • Aciertos: Puntos donde se siguio el plan correctamente
  • Lecciones: Aprendizajes para proximos game plans

STOPS

  • Detalle por stop: Trade numero, instrumento, perdida, distancia en puntos, distancia/ATR, tipo de stop (tight-stop, adecuado, etc.), analisis y recomendacion
  • Tabla resumen: Total stops, total perdido, stops adecuados, stops ajustados
  • Patron general: Patron identificado en los stops de la sesion
  • Recomendacion general: Acciones para mejorar la gestion de stops

DOFA

Matriz 2x2 con:

  • Fortalezas (F): Aspectos positivos de la sesion
  • Debilidades (D): Aspectos a mejorar
  • Oportunidades (O): Areas de oportunidad detectadas
  • Amenazas (A): Riesgos identificados para sesiones futuras

RECOMENDACIONES

Lista de recomendaciones especificas con titulo y puntos de accion. Tambien incluye:

  • Bugs e Incidencias: Problemas tecnicos detectados con severidad (ALTA/MEDIA/BAJA) y solucion propuesta

ANALISIS IA

  • Resumen Ejecutivo: Texto generado por la IA describiendo el rendimiento general
  • Nota Final: Resumen y cierre del analisis post-market
  • Para cierre semanal: Seccion extra con resumen semanal, comparativa dia a dia y conclusion
  • Para cierre mensual: Seccion extra con resumen mensual, estadisticas agregadas y conclusiones

TABLA COMPLETA DE TRADES

Tabla con todos los trades de la sesion incluyendo: numero, estrategia, instrumento, direccion, entry/exit time, entry/exit price, cantidad, PnL (codificado por color), entry name y exit name. Con paginacion incorporada (10 trades por pagina) para sesiones con muchos trades.

9Troubleshooting

Solucion de problemas comunes

Problemas frecuentes y como resolverlos.

Error: No se encuentra la carpeta Post-Mercado/{fecha}
Carpeta no encontrada: Post-Mercado/20260523

Solucion: La carpeta se genera al exportar CSVs desde NinjaTrader 8. Asegurate de que:

  • Exportaste los trades desde NT8 despues de la sesion
  • La carpeta de destino es Post-Mercado/{YYYYMMDD}/
  • El formato de fecha coincide (YYYYMMDD, ej: 20260522)

Si el dia no se opero (festivo, fin de semana), puedes usar --skip-ai para generar un informe vacio.

Error: API key no configurada
ERROR: API key para groq no configurada.

Solucion: Abre config.json y verifica que la clave api_key tenga el valor correcto. O configura la variable de entorno correspondiente (GROQ_API_KEY, GEMINI_API_KEY, etc.).

Error: El prompt excede el limite de tokens de Groq
Error code: 429 - Request too large

Solucion: Groq tiene un limite de 12,000 TPM (tokens por minuto). Si tu prompt es muy grande (muchos trades), intenta:

  • Usar Gemini (limite mas generoso)
  • Usar modo Manual (opcion 6) con ChatGPT o Claude web
  • Reducir la cantidad de trades en el CSV (exportar solo los relevantes)
La IA no genera todos los campos esperados

Solucion: Prueba con otro proveedor. Groq (Llama 3.3 70B) y Gemini suelen dar los mejores resultados. Si el analisis viene incompleto, prueba el modo Manual (opcion 6) con ChatGPT o Claude web que suelen seguir mejor las instrucciones.

El JSON de respuesta de IA no se parsea correctamente
Error parseando JSON de IA

Solucion: El sistema guarda la respuesta cruda en ai_raw_response_postmarket.txt. Abre ese archivo para ver que respondio la IA exactamente. Si la respuesta tiene texto adicional fuera del JSON, corrige el prompt o prueba con otro proveedor. Si usas modo Manual, asegurate de que la respuesta sea UNICAMENTE JSON (sin bloques ``` ni markdown).

Ollama no responde
Error: Cannot connect to host localhost:11434

Solucion: Asegurate de que Ollama esta instalado y corriendo. Abre PowerShell y ejecuta ollama list. Si no aparece, inicia Ollama desde el menu de inicio. Luego ollama pull qwen2.5-coder:7b si no lo has descargado.

Git push falla
Error en git push

Solucion: Asegurate de que el repositorio tiene un remote configurado. Ejecuta git remote -v dentro del repo. Si no hay remote, agrega: git remote add origin <url>. Verifica tambien que las credenciales de GitHub esten configuradas. En algunos casos, el token de acceso personal puede haber expirado.

El HTML se genera pero no se ve en la web

Solucion: Cloudflare Pages tarda ~30 segundos en desplegar despues del push. Espera un minuto y refresca. Verifica que el archivo existe en el repositorio de GitHub (edus-trader/postmarket_{fecha}.html). Si el archivo esta pero no carga, probablemente Cloudflare esta re-desplegando.

Pro tip: atajo de doble click

Usa el archivo INICIAR_POSTMARKET_AUTO.bat para ejecutar todo automaticamente sin abrir PowerShell:

  1. Navega a eduSTrader - Local Free/gameplan_system/
  2. Haz doble click en INICIAR_POSTMARKET_AUTO.bat
  3. El sistema busca los CSVs, llama a la IA (proveedor por defecto), genera el HTML y publica

Para ejecucion completamente desatendida (programable con Windows Task Scheduler):

python generar_postmarket.py --auto
