Cómo regenerar los datos

Para actualizar este dashboard con nuevas señales, ejecuta el siguiente proceso en dos pasos:

Paso 1 — Exportar señales desde NinjaTrader 8

1. Abre NT8 y carga el indicador EduS_MasterPanel_HUD_V4 (o V4-1) 2. Activa RegistrarSenales = true 3. Configura RutaLog a tu carpeta de análisis 4. El archivo se genera automáticamente (ej: senales-edus.csv) 5. Copia el archivo a la carpeta EduSTrader - Local Free

Paso 2 — Ejecutar el script de correlación

cd "C:\Users\eduar\OneDrive - Desarrollo Personal\Documents - Operativa Diaria\EduSTrader - Local Free" # Primero depura y cruza con VIX (si tienes nuevas señales): python generar_data_depurada.py # Luego genera la correlación VIX + Keltner + ATR: python generar_vix_keltner_estadisticas.py # Finalmente regenera el dashboard: python build_dashboard_vix.py

Requisitos del VIX (VIX_H1_2anios.csv)

El archivo VIX_H1_2anios.csv se descarga desde Yahoo Finance (^VIX, intervalo 1H). Formato esperado: - Fila 1: Price,Close,High,Low,Open,Volume - Fila 2: Ticker,^VIX,^VIX,^VIX,^VIX,^VIX - Fila 3: Datetime,,,,, - Fila 4+: 2024-05-07 07:00:00+00:00,13.59,... Para descargarlo en Python: import yfinance as yf vix = yf.download("^VIX", period="2y", interval="1h") vix.to_csv("VIX_H1_2anios.csv")
